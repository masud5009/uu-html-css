About the project

The Uttara University Premier League (UUPL) is an inter-department cricket tournament website built as an academic web engineering project. It is crafted entirely with pure semantic HTML5 and modern CSS3: the responsive navigation, fixture radio tabs, official league rules, and rolling ball animation all work seamlessly without a single line of JavaScript.
